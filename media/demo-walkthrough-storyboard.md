# 2-Minute Demo Walkthrough Storyboard

正式视频可按以下脚本录制。

## 0:00 - 0:20 背景

展示制造业 BI 平台中大量报表目录，说明 AI 问数常见问题：找不到报表、口径不清、字段影响难判断。

## 0:20 - 0:45 扫描

展示扫描入口，选择报表源或上传脱敏报表，启动解析任务。

## 0:45 - 1:10 资产浏览

展示资产列表，进入一张 PO-SO 一致性分析报表，查看报表摘要、数据集、源表和字段。

## 1:10 - 1:35 影响分析

输入一张物理表或视图，查看哪些报表和数据集引用了它。

## 1:35 - 2:00 MCP 查询

通过 MCP / Agent 查询“有哪些产能相关报表资产”，展示 AI 基于资产上下文回答。
