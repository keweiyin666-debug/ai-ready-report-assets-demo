# FAQ

## 这是开源项目吗？

不是。这个仓库是公开 Demo 和交流材料，不包含生产解析器源码，也不提供完整可运行系统。

## 为什么不放真实报表文件？

BI 报表文件中可能包含 SQL、字段名、目录结构、业务口径、连接信息和客户组织信息。公开真实文件存在数据安全风险。

## MCP 在这里起什么作用？

MCP 用于让 AI / Agent 查询报表资产，例如搜索资产、读取摘要、获取 Spec、查找指标线索或反查表字段影响范围。

## 这能直接回答业务问题吗？

Demo 展示的是“先把报表变成 AI 可用资产上下文”的前置能力。AI 回答业务问题时，应先检索资产、确认口径、定位来源，再组织回答。

## 适合哪些企业？

适合已经沉淀大量 BI 报表，并正在做 AI 问数、指标治理、数据资产盘点、报表迁移或 BI 运维提效的企业。
